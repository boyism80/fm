선택한 스위트에 적용

serial 스위트(결혼·택배·고용상인처럼 서버 전역 상태를 쓰는 스위트)는 병렬 단계가 끝난 뒤 클러스터 전체에서 하나씩 실행합니다.

Agent는 스위트를 시작할 때마다 자기 디스크의 스위트 파일과 바뀐 lib 스크립트를 다시 읽으므로, 스크립트 수정은 재시작 없이 다음 스위트에 반영됩니다. 스위트 목록이 바뀌면 다시 읽기를 누르세요.

seat 수는 Agent마다 -seats로 정하고, Master가 Agent마다 겹치지 않는 seat 번호(인스턴스 슬롯)를 나눠 줍니다.
